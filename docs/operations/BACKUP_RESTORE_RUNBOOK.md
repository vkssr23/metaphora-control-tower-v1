# Backup and Restore Runbook

Status: DOCUMENTED_NOT_EXECUTED. The controlled-staging drill must use a separate empty restore database and separate document root; it must never overwrite the source staging environment.

Back up Mongo with an approved encrypted staging mechanism, immutable local/object document bytes, and separately managed configuration/secrets. Never place secrets in the backup manifest. Preserve audit events with the data snapshot. Record snapshot boundaries and file hashes. Restore in order: configuration references, Mongo, documents, then application. Validate tenant/load counts and isolation, RC/POD SHA-256 and object presence, invoice/package/readiness state, audit presence and integrity, manifest indexes, Golden Flow, outbox/reconciliation consistency, and Action Center refresh. Record backup duration, restore duration, verification duration, observed data-loss window, and cleanup. Targets are RPO 24 hours and RTO 8 hours; neither is measured. A disposable staging drill is required before customer data.
