# Controlled Pilot SLO Targets

Measurement is not yet deployed. Targets: API availability 99.5% monthly; server error rate <1%; normal read p95 ≤500 ms; document retrieval first byte p95 ≤2 s; Action Center freshness follows successful bounded refresh, not real-time delivery; RPO 24 hours and RTO 8 hours pending backup validation.

Incidents: P0 includes cross-tenant exposure, unauthorized pickup authority, duplicate financial authority, document confidentiality breach, or authoritative audit loss/corruption. P1 includes Action Center outage or blocked invoice/document workflows. P2 includes noncritical UI/reporting discrepancies.
